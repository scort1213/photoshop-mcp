# Local-build project description

This fork controls local Photoshop through MCP stdio. It retains ordinary editing, recipes, custom scripts and recorded actions. Built-in cloud operations, analytics and standalone cloud chat are disabled.

Use this checkout’s built executable. Upstream npm packages, legacy promotional images and earlier website content do not describe this build. See [the current README](../README.md), [local operation policy](../LOCAL_ONLY.md) and [verification results](../LOCAL_ONLY_ACCEPTANCE.md).
