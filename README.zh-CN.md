# Photoshop MCP 本地运行版

通过 MCP 控制本机 Photoshop，支持 Windows 和 macOS。普通编辑、自定义脚本和录制动作继续保留；内置云生成、使用统计和独立云聊天界面已关闭。

## 安装与接入

首次安装需要下载依赖。进入此项目目录执行：

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm run build:server
```

在 MCP 客户端中，将启动命令设为本机 Node 的绝对路径，参数设为此目录的 `dist/index.js` 绝对路径。客户端会自动启动服务。

必须使用本分支的本地构建，不能改用上游 `npx @alisaitteke/photoshop-mcp`。日常启动不会安装依赖、打开浏览器、校验账号或发送使用统计。旧配置里的 `ANALYTICS_DISABLED=1` 可以保留，但现在无论该变量是什么，统计都不会开启。

## 保留的能力

图层、文字、选区、蒙版、变换、本地文件读写和普通配方继续使用。

- 去杂物固定使用内容识别填充，不先试生成式 AI。
- 人像增强使用普通本地修图。
- 天空合成使用本地图片与渐变蒙版。
- 生成式填充、扩图、生图、生成式放大、神经滤镜等内置入口被关闭；旧客户端直接请求会收到 `cloud_disabled`。
- 自定义脚本和录制动作继续保留灵活性；指令要求不调用云、联网、账号登录或云端替代。

自动抠图、选择主体和证件照仍可使用，但应先在 Photoshop 的“设置／首选项 → 图像处理”中，将“选择主体和移除背景”设为“设备”。项目没有可靠接口强制这个设置，因此它是使用与验收前提。

自定义脚本只加指令，没有沙箱或强制检查，不能保证任意脚本都无法绕过。Adobe 自身登录、后台联网及 AI 客户端的模型处理不在本项目保证范围内。

## 文件与保存操作

- 选择真实本地文件并使用完整绝对路径；不接受相对路径、`~`、Finder 别名、快捷方式或网络位置。文件名中的中文、空格、引号和百分号可正常使用。
- “保存后关闭”现在会**保存后保持文档打开**，结果明确显示“已保存、未关闭”。由你确认后关闭，助手不会自动用“不保存关闭”补做下一步。
- 执行超时后不要重复发送编辑：先查看当前状态，再明确恢复。结果不确定的临时文件会保留，并提供检查位置。
- Windows 当前要求本地 Node 与真实 Windows 系统目录位于同一盘；不符合时明确报配置错误，不改用网络或 PATH 中的替代程序。

### 本轮升级后重载

等待旧任务结束并检查 Photoshop 当前状态，然后统一停止并重新加载所有连接本项目的 MCP 客户端。新版使用已检查的本地专用锁目录，不能让采用旧锁目录的客户端继续并行运行。若旧版还有“结果未知”提示，应先检查并恢复，不能通过更换目录绕过它。Mac 自动查找仅限 `/Applications`；装在其他本地位置时需配置 `PHOTOSHOP_PATH`。
